06 · Competency Assessment & Credential

การประเมินสมรรถนะและการออก Credential

94.3%

ได้รับ Credential — 82 จาก 87 ผู้เข้าเรียนจริง

82Credential Recipients

94.3% คืออัตราการได้รับ Credential — ไม่ใช่การแจกแจงคุณภาพผลงาน

กรอบการประเมินสมรรถนะ

  • Competency-based Assessment — ผลงานพิสูจน์ว่า “ทำได้จริง”
  • Instructor Evaluation — ประเมินโดยผู้สอนในแต่ละหัวข้ออย่างต่อเนื่อง
  • Presentation — นำเสนอต่ออาจารย์และคณะกรรมการจากอุตสาหกรรม
  • Real-world Projects — โครงการที่ใช้งานได้จริงในอุตสาหกรรม
  • แบบทดสอบเชิงปฏิบัติ SPLO — เกณฑ์ผ่านมากกว่า 75%
กรอบ Competency Assessment รับรองว่าผู้เรียนส่วนใหญ่บรรลุ Credential ผ่านการพิสูจน์สมรรถนะที่ทำได้จริง

08 · Learner Feedback & Lessons Learned

เสียงสะท้อนและบทเรียนที่ได้รับ

จัดบ่อยขึ้น 54%
On-site / Workshop 31%
เชิงลึกขึ้น 15%

Lessons Learned

  1. ทีมผู้สอนรับผู้สมัครทั้งหมดเกินแผนรับ 40 คน/รุ่น โดยไม่ปฏิเสธผู้สมัคร
  2. Hands-on และ On-site / Workshop ยังสำคัญต่อสมรรถนะเชิงปฏิบัติ
  3. มีความต้องการ Advanced Course และเนื้อหาเชิงลึก
  4. ออกแบบเส้นทางเรียนรู้เป็นลำดับขั้นให้สอดคล้อง SPLO / Credential
  5. ติดตาม Workplace Application หลังจบหลักสูตรอย่างเป็นระบบ
ข้อเสนอแนะสะท้อนทั้งความต้องการให้ดำเนินหลักสูตรต่อเนื่อง และโอกาสพัฒนา Hybrid Learning
