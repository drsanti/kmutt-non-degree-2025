# Non-Degree Full-Stack Presentation

HTML presentation สำหรับผลการดำเนินงานหลักสูตร Non-Degree  
**Full-Stack Software Developer for Industrial Automation Systems**

## เปิดดูในเครื่อง

เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือรัน:

```bash
python -m http.server 8765 --directory ND02-68/presentation
```

แล้วเปิด http://localhost:8765/

## GitHub Pages

1. Push โฟลเดอร์นี้ขึ้น GitHub repository
2. Settings → Pages → Deploy from branch
3. เลือก branch และโฟลเดอร์ `/` หรือ `/docs` ตามโครงสร้าง repo
4. ถ้าเก็บไว้ที่ `ND02-68/presentation/` URL จะประมาณ:

`https://<user>.github.io/<repo>/ND02-68/presentation/`

ฟอนต์โหลดจาก Google Fonts (Prompt + Sarabun) จึงใช้งานได้ทั้ง local และ GitHub Pages โดยไม่ต้องติดตั้งฟอนต์เพิ่ม
